## Setup Instructions

1. **Add Your Profile Picture**
   - Place your profile picture in the `website` folder
   - Name it `me.JPG` (or update the image source in `index.html`)

2. **Update Contact Information**
   - Edit the contact section in `index.html` to add your:
     - Email address
     - LinkedIn profile
     - Other contact details

3. **Customize Content**
   - Modify expertise, skills, or experience as needed
   - Update certifications and achievements

4. **Launch the Website**
   - Open `index.html` in a web browser
   - Or deploy to a web hosting service

## Customization Tips

### Colors
The color scheme uses CSS variables defined in `styles.css`:
- `--primary-color`: #0078d4 (Microsoft Blue)
- `--secondary-color`: #00bcf2
- `--accent-color`: #50e6ff

### Adding New Sections
To add new content sections:
1. Add the HTML structure in `index.html`
2. Style it in `styles.css`
3. Add any interactive features in `script.js`
4. Update the navigation menu

### Form Integration
The contact form currently logs to the console. To integrate with a backend:
1. Update the form submission handler in `script.js`
2. Connect to your preferred backend service (e.g., FormSpree, EmailJS, or custom API)
